# ELFATH-STATIO

**EL FATH STATIO — الفتح ستاتيو** · Librairie jeune algérienne (Alger). En ligne et en magasin.

> **Books that hit different.** Algerian, online, and in-store. Pas le livre de tes parents.

Brand kit **« Flash & Paper »** : un flash de phone sur un poche à Alger — pas une librairie poussiéreuse.

## Contenu

- [`index.html`](index.html) — page marque vivante (téléphone d'abord) : héros, highlights, palette, typo, motifs, template Stories, vitrine, voix, CTA double.
- [`BRAND.md`](BRAND.md) — le kit verrouillé : couleurs, typo, prompts finaux, exports, système social, 10 légendes, semaine de Stories.
- [`brand/assets/`](brand/assets/) — logo monogramme dog-ear (SVG + PNG), wordmark bilingue (SVG), profile pic, template Stories, vitrine, tote + marque-page.
- [`assets/css/style.css`](assets/css/style.css) — design system : tokens, stickers, badges, grain riso, dog-ears.
- [`assets/fonts/`](assets/fonts/) — Fraunces · Inter · Cairo (SIL OFL, auto-hébergées).
- [`assets/js/main.js`](assets/js/main.js) — copie des légendes, sticker DISPO ⇄ RUPTURE.

## Voir le kit

```bash
python3 -m http.server 8000
# puis http://localhost:8000
```
